An ensemble machine learning system combining XGBoost, LightGBM, and CatBoost for phishing website detection, achieving 93.71% accuracy and 99% phishing recall. Incorporates SHAP-based interpretability for explainable predictions.

Accepted at **ICCIT 2025** (IEEE).
